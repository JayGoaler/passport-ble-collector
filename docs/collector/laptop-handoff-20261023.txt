五、需要现场开发时的 Windows 隔离构建

先检查 build/windows-native 是否已存在及其来源；不删除已有目录求通过。
若不可信，选择新的短英文构建目录并同步以下变量。PowerShell 示例：

  $repo = (Get-Location).Path
  $build = Join-Path $repo 'build\windows-native'
  $config = Join-Path $build 'sdkconfig'
  $defaults = Join-Path $repo 'sdkconfig.defaults'
  $env:IDF_TARGET = 'esp32c3'
  $env:IDF_TOOLCHAIN = 'gcc'
  New-Item -ItemType Directory -Force -Path $build | Out-Null
  idf.py -B $build -D "SDKCONFIG=$config" -D "SDKCONFIG_DEFAULTS=$defaults" reconfigure
  if ($LASTEXITCODE -ne 0) { throw '配置失败，停止' }
  cmake --build $build --parallel 2
  if ($LASTEXITCODE -ne 0) { throw '构建失败，停止' }
  idf.py -B $build -D "SDKCONFIG=$config" merge-bin -o "$build/FoloToy-AI-Passport-full.bin"
  if ($LASTEXITCODE -ne 0) { throw '合并失败，停止' }
  python tools/verify_firmware.py $build
  if ($LASTEXITCODE -ne 0) { throw '镜像校验失败，停止' }
  python tools/archive_firmware.py create $build
  if ($LASTEXITCODE -ne 0) { throw '调试归档失败，停止' }

记录最后输出的实际归档目录，再执行 tools/archive_firmware.py verify 实际归档目录。
保存 BIN、匹配 ELF/MAP、bootloader、partition-table、flash_args 和 manifest。
确认目标 ESP32-C3、8 MB Flash、无 PSRAM、USB Serial/JTAG，并核对 dependencies.lock。
Windows 原生构建不是 Mac 完整门禁的替代；Bash/C/workflow 不兼容项应记录 NOT RUN，
不可删测试或修改门禁隐藏它。目标未执行的命令与本次源端报告分开。
