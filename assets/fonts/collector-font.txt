输入 SHA-256：collector-font-source.sha256。
输出：collector_font_16.c，16 px、4 bpp、不压缩、无 kerning；固定界面文案及 ASCII。
中文清单：collector-symbols.txt，自动提取 collector_ui.c 和 collector_controller.c 的字符串。

重新生成（开发工具，不是固件运行依赖）：
  npm install --prefix /tmp/passport-font-tools --no-audit --no-fund --ignore-scripts lv_font_conv@1.5.3
  python3 tools/generate_collector_font.py --converter /tmp/passport-font-tools/node_modules/.bin/lv_font_conv
Windows 可将临时目录替换为本地目录，并通过 --converter 指定 lv_font_conv.cmd。
若本地尚未获取 LVGL，可先运行固件构建下载锁定依赖，或显式指定 --lvgl-root。
